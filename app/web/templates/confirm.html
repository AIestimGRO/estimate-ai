$warning
Настройки подбора

Стандартный режим — все три опции ниже выключены: точный код, совпадающая единица измерения и раздельный монтаж/демонтаж.

Префикс семейства не учитывается: например, ФЕР27-06-026-01 сможет совпасть с ГЭСН27-06-026-01. Подтипы р/м сохраняются.

Расширенный режим: поиск идёт по коду без привязки к единице измерения. Используйте только для нестандартных запросов — цены из разных единиц могут быть несопоставимы.

Если включено, признак демонтажа не ограничивает список аналогов.

Для каждого подобранного аналога РНМЦ Qwen3 ищет ТКП-аналог только среди кандидатов его задачи после проверки единицы и количества. Соседний столбец создаётся только если ТКП-аналог реально найден; цена войдёт в расчёт средней.
